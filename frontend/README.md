# Sky Nest Hotels - Luxury Hotel Website

An elegant and luxurious hotel website built with React, featuring modern design, smooth animations, and mobile responsiveness.

## Features

- **Elegant Design**: Luxury hotel branding with premium aesthetics
- **Responsive Layout**: Optimized for desktop, tablet, and mobile devices
- **Smooth Animations**: Engaging animations and transitions throughout
- **Interactive Components**: Dynamic booking forms, image galleries, and user interactions
- **Local Image Integration**: Uses images from the Images and Figmaimages folders
- **Component-Based Architecture**: Well-organized, reusable React components

## Pages & Components

### Main Pages
- **Home Page**: Hero section, rooms showcase, facilities, testimonials
- **Booking Page**: Comprehensive booking form with validation
- **Offers Page**: Special deals and discounts with filtering
- **Contact Page**: Contact form and location information
- **Login Page**: User authentication with sign up/sign in

### Key Components
- **Navigation**: Responsive navbar with smooth animations
- **IntroPage**: Animated landing page with luxury branding
- **Footer**: Complete footer with social links and newsletter signup

## Getting Started

### Prerequisites
- Node.js (version 14 or higher)
- npm or yarn package manager

### Installation

1. **Clone or download the project**
   ```bash
   cd "D:\Database project"
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm start
   ```

4. **Open your browser**
   Navigate to `http://localhost:3000` to view the website

### Styling
- Main styles are in `src/styles/App.css`
- Uses CSS custom properties for theming
- Tailwind CSS for utility classes
- Component-specific styles inline

### Images
- Place your images in the `Images/` folder

- Fallback images are provided for missing assets
